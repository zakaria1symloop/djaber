# 02 — Next.js route map (App Router)

`apps/web`, Next.js App Router, TypeScript strict, Tailwind + `packages/ui`. Data via TanStack Query over `/api/v1` (07 §4); no server-side DB access. Locale prefix in the URL: `/{locale}/…` with `locale ∈ fr|ar|en` (fr default). Routes below omit the prefix.

Every route row: **Route** → **Figma frame** (exact name on page "Web V2") → **API endpoints** (canonical paths of `docs/specs/06-api.md`, relative to `/api/v1`) → **Required permission** (keys of `01-nest-module-map.md` §3.2, the single permission table: merchant `<group>.<action>`, platform `admin.<area>.read` / `admin.<area>.write`) → **States** (from `12-screen-states.md` and the GLOBAL catalogue; `L6` = the 6 list states, `F` = form states, `D` = detail states, all defined in §4). The route paths below are the canonical deep links: notifications (`03-events-and-jobs.md` §5.1) and the mobile app (`djaber://` + same path) use them verbatim.

    settings/integrations/layout.tsx # IntegrationsTabs: sheets · api-keys · webhooks (routes /settings/integrations/[tab])

Layout hooks (mounted once in `(app)/layout.tsx`, also active in `(admin)/layout.tsx` for the first two):
- **Legal re-acceptance interstitial** — on mount and after every `403 LEGAL_REACCEPT_REQUIRED` response, `GET /legal/pending`; when non-empty, render the blocking dialog `GLOBAL — States, toasts, banners & system dialogs catalogue` ("Conditions mises à jour": document title, link to `/legal/[key]`, checkbox, button "Accepter") and call `POST /legal/accept { key, version }` per document; the app is unusable until the list is empty (also reached by the notification deep link `/legal/:key`).
- **Maintenance banner** — `GET /status` on mount + every 60 s; `maintenance.scheduledFrom/To` ⇒ banner id `maintenance` (info, top of the priority list, text from `PlatformSetting.maintenance`); a write refused with `503 MAINTENANCE_MODE {until}` ⇒ the same banner (active, "lecture seule") + the error inline (11 §12.1 "banner + disabled actions"); a READ refused with `503 MAINTENANCE_MODE` (window scope `all`) ⇒ full-page `GLOBAL — Offline`-style state "Maintenance en cours" with automatic retry every 60 s.
- **Announcements** — `GET /announcements` on mount (active `CmsEntry` announcements for the plan/workspace); each renders as banner id `announcement` (info, dismissible) below every other banner; "Fermer" calls `POST /announcements/:id/dismiss` (persisted in `User.prefs.dismissedAnnouncementIds`). The `platform.announcement` notification deep-links to `/notifications`.

### 2.1 `MerchantShell`
- `Sidebar` (240 px ≥ 1280; icon rail 64 px at 1024–1279; drawer < 1024 — frame `RESP — Responsive — 1024 icon sidebar · 390 mobile web · simple-mode sidebar`). Items and order exactly as frame `ANA-01 — Home — default`: Accueil, File d'attente (badge), Boîte de réception (badge), Commandes, Livraison & suivi, Clients, group STOCK (Tableau de bord stock, Produits, Catégories, Mouvements*, Fournisseurs*, Achats*, Ventes*, Caisse*, Recommandations), group IA & CANAUX (Agents IA, Pages connectées), group ANALYSE (Statistiques, Rapports — kept in simple mode with its 9 simple reports, 12 §24), footer Notifications (badge), Paramètres, Aide. `*` hidden when `workspace.stockMode === 'simple'` (D12). Active item fill `ink/raised`.
- `TopBar`: `WorkspaceSwitcher` (only when memberships > 1), `CreditsPill` (`used / limit`, red when exhausted, links `/settings/credits`), bell (`unreadCount` from `GET /notifications/unread-count`, WS `notification.created`), `UserMenu` (Profil, Langue, Créer un espace (only if `ownedWorkspaceId === null`), Plateforme (platformRole only), Déconnexion, Déconnecter tous les appareils).
- `BannerStack` (one at a time, priority from GLOBAL frame): maintenance > suspended > channel needs reconnect > credits 100 % > plan expired > credits 80 % > plan expiring > approval pending > e-mail unverified > read-only member > new version available > offline > announcement. "suspended" = `Workspace.status === 'suspended'`; "plan expired" = `Subscription.status === 'expired'` (free limits applied, D44); "read-only member" = `membership.readOnly` (plan `maxMembers`). Impersonation sessions render the fixed top bar "Vous agissez en tant que {workspace} · lecture seule · {mm} min · Quitter" above the stack (admin side only).
- `ToastRegion` bottom-right, max 3, 5 s.
- `WsProvider` (Socket.IO, rooms `ws:<workspaceId>`, `user:<userId>`; `auth.expiring` ⇒ refresh; reconnect ⇒ `resync`; disconnected ⇒ "reconnexion…" pill + 15 s polling on active queries).
- Keyboard: `Ctrl+K` focuses current list search; `?` opens shortcuts help (GLOBAL frame list).

### 2.2 `SettingsShell`
Sub-nav (frame `SET — Settings — Integrations …`): Profil, Espace de travail, Membres, Mode stock, Réponses rapides, Messages système, Sécurité, Intégrations, Plan & facturation, Crédits, Zone de danger. Items requiring `workspace.settings`, `integrations.manage` or `billing.read` are hidden for Operators; `Membres` is visible to every member (`members.read`) with actions only for the Owner (`members.write`, `workspace.transfer`); `Zone de danger` is hidden for non-owners (`workspace.delete`); `Plan & facturation` is read-only for Admin (`billing.read` without `billing.plan`; packs/promo/pay invoice stay enabled via `billing.write`); `Crédits` shows the balance to every member (`billing.read_credits`) and the ledger to Admin+ (`billing.read`).

### 2.3 `AdminShell`

Every item is visible (every role has `admin.<area>.read`); write controls are hidden without the matching `admin.<area>.write` key of `01-nest-module-map.md` §3.2.

Resume rule: `(app)/layout` redirects to `/onboarding/<step>` when `workspace.onboardingStep < 6` and the user did not click "Passer la configuration" (`onboardingStep = 99` on skip). Leaving a step never moves the saved step back.

## 6. Data layer conventions

- `apps/web/src/api/client.ts`: fetch wrapper adds `Authorization` (in-memory access token), `X-Workspace-Id`, `Accept-Language`, `Idempotency-Key` (uuid v4 per submit attempt, reused on retry) for the routes listed in `api-contract.md` §1.7; maps the error envelope to `ApiError { code, message, params, fields, details, ref }`; on 401 performs one silent refresh then redirects to `/login?returnTo=`; `403 LEGAL_REACCEPT_REQUIRED` ⇒ legal interstitial, `503 MAINTENANCE_MODE` ⇒ maintenance state (§1 layout hooks); `409 WORKSPACE_DELETION_SCHEDULED` ⇒ toast + link to `/settings/danger`.
- Query keys: `[workspaceId, 'orders', filters]`, `[workspaceId, 'order', id]`, …; WS handlers call `queryClient.setQueryData` for `order.updated`, `conversation.updated`, `message.created`, `shipment.updated`, `notification.created`, `credits.updated`, `job.updated`, `channel.updated` and `invalidateQueries` for lists.
- Forms: `react-hook-form` + zod schemas from `packages/shared`; `fields` from the server mapped with `setError(field, { type:'server', message: t('validation.'+code) })`; unknown field ⇒ form-level alert.
- Mutations never auto-retry except idempotent ones; GETs retry 3× with backoff when offline flag clears.
- Drafts: wizard/agent/product forms persist to `sessionStorage` keyed by route for session-expired recovery.

## 7. RTL + i18n

- `next-intl` with messages `apps/web/messages/{fr,ar,en}.json` generated from `packages/shared/src/i18n` (06-i18n-copy-deck). CI script `pnpm i18n:check` fails on any key missing in any locale (AT-UX-02).
- `<html lang dir>` from the locale; `dir="rtl"` for `ar`. Only logical CSS (`ms-`, `me-`, `ps-`, `start`, `end`); Tailwind `rtl:` variants forbidden except for icon mirroring (`rtl:-scale-x-100` on directional icons: chevrons, arrows, send).
- Fonts: Geist (body/title), Syne (display), JetBrains Mono (labels), **Changa** for `ar` body via `font-family` swap on `html[lang=ar]` (Body AR text style, 08 §1).
- Numbers, phones, SKUs, order numbers, URLs, amounts: wrap in `<Ltr>` (`unicode-bidi: isolate; direction: ltr`) — `DataTable` columns with `ltr: true` do this automatically.
- Formats: dates `dd MMM yyyy` / `HH:mm` in `Africa/Algiers`, relative "il y a 2 min" via `Intl.RelativeTimeFormat`; currency `12 500 DA` (space thousands, no decimals, suffix "DA" in all locales — Arabic uses "دج" only inside customer messages, never in the merchant UI); percentages `68 %` (narrow no-break space in fr).
- Date pickers mirrored in RTL; charts keep LTR axes.
- Pluralisation via ICU messages (`{count, plural, =0 {…} one {…} other {…}}`); Arabic needs `zero/one/two/few/many/other`.

## 8. Do / Don't

**Do**
- Put every filter, tab, sort, page, density and open sheet id in the URL.
- Render every disabled control with a `Tooltip` reason; use `disabledReason` codes from 11.
- Use `ActionsDropdown` for every data row; one primary action first.
- Use the `StatusPill` map for every enum value; never pick a colour ad hoc.
- Show server field errors inside the open dialog; keep the form content.
- Update the query cache from WS events; fall back to 15 s polling when disconnected.
- Wrap numbers/phones/SKUs in `<Ltr>` in RTL.

**Don't**
- Don't fetch from the DB in server components; the API is the only data source.
- Don't store access tokens in `localStorage`; keep them in memory, refresh via cookie.
- Don't hardcode strings; every label is an i18n key.
- Don't add a route, tab or dialog that has no Figma frame or spec ID.
- Don't duplicate the status filter outside the tabs (ORD-05 fix).
- Don't auto-retry non-idempotent mutations.
- Don't use physical CSS directions (`ml-`, `left-`).
