# Djaber v2 — Specifications

Rebuild of Djaber AI (AI sales agent for Facebook / Instagram shops, Algerian market) on a clean stack: **NestJS** (API + worker), **Next.js** (web) and the **Flutter** mobile app (Android + iOS), all on one API.

**Principle:** v2 = V1 feature-for-feature on the retained modules (100 % parity, see 01 §4), every V1 defect closed, every interaction designed from the user's seat, nothing invented beyond the sources below.
