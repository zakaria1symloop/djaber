# 03 — Functional modules

Each requirement has an ID, a phase (P0–P3, 01 §5) and a source. Acceptance criteria (AC) are testable; [13-acceptance-tests.md](13-acceptance-tests.md) lists the scenarios. Flows with failure branches are in [10-user-flows.md](10-user-flows.md) (`FL-nn`). Baseline is V1 unless marked **fix** (V1 defect closed) or **new** (CDC/PH2/v2 decision).
